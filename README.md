### Getting started

```bash
cp .env.example .env
npm install
npm run docker:up
npm run start:dev
```

### API documentation

Swagger UI: http://localhost:3000/docs

### Mail (Mailpit)

In the dev environment, emails (e.g. OTP codes) aren't sent to a real SMTP server — you can view them in the Mailpit web UI: http://localhost:8025
